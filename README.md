# Форма — бьюти-мастера

Интерактивный портфолио-концепт. Выбор услуги → мастер и работы → демозаявка.

## Запуск
Откройте `dist/index.html` или запустите `python -m http.server 8000 --directory dist`.

## Реализовано
Адаптивный каталог, шесть категорий, фильтры и поиск, профили мастеров, избранное, форма заявки с проверкой даты/телефона, локальная история и отмена заявок. Данные хранятся в localStorage; телефон не сохраняется.

## Ограничения
Это клиентский прототип, без сервера, реальных мастеров, отправки заявок, авторизации и проверки документов. Все профили, отзывы, адреса и цены демонстрационные. Фото Unsplash иллюстрируют интерфейс и не являются работами указанных людей. Локальные заявки не подтверждают посещение. Не вводите реальные персональные данные.

## Дизайн
Тёплая светлая палитра, сливовый акцент, крупная фотография результата, понятные подписи, последовательное раскрытие информации.
