# Форма — платформа выбора бьюти-мастеров

Портфолио-прототип: выбрать работу, сравнить мастеров, указать бюджет/район/время и согласовать заявку. Светлый интерфейс с синими действиями и жёлтыми ценниками, сначала для мобильного веба.

## Запуск

Открыть `dist/index.html` либо запустить статический сервер из `dist`. Для загрузки файлов рекомендуется HTTPS или localhost. Сборка и зависимости для приложения не нужны. GitHub Pages публикует `dist` существующим workflow после объединения изменений в `main`.

## Что работает

- Каталог шести исходных мастеров, поиск по имени/специализации/услуге, категории, бюджет, район и сортировка.
- Профили, работы, отзывы, услуги и их стоимость, избранные мастера и работы.
- «Соберём ваш визит»: необязательное фото-референс, услуга, бюджет, район, день и время. Подбор по параметрам и рабочим часам; фото не анализируется автоматически.
- Заявка: выбор пожеланий → проверка услуги, времени, цены и контактов → отправка в локальное хранилище. Изменение и отмена доступны в «Записях».
- Кабинет клиента: имя, контакт в текущей сессии, заявки и избранное.
- Демокабинет мастера: редактирование профиля и рабочих часов, услуг, работ с фотографиями до/после; предложение точного времени и цены, отклонение и завершение визита.
- Клиент отдельно принимает предложение мастера. Проверяются рабочие часы, длительность и пересечения с подтверждёнными записями/предложениями.
- Документы: тестовые PDF/JPG/PNG/WebP до 8 МБ, локальное хранение файла, просмотр, удаление; демоочередь модерации с причиной возврата. Одобренные документы появляются в локальном профиле с честной демонстрационной отметкой.
- После завершённого демовизита клиент может оставить один отзыв.
- Старые ключи `forma-saved` и `forma-bookings` переносятся при первом запуске новой версии. Исходные мастера, фотографии и тексты сохранены.

## Ограничения прототипа

Это статическое демонстрационное приложение, **не работающий многопользовательский сервис**. Роли переключаются открыто для проверки сценариев. Нет серверной авторизации, контроля доступа, настоящей модерации, SMS, чата, уведомлений, платежей или синхронизации между устройствами. Реальные персональные документы загружать не следует.

Заявки, справочники, отзывы и избранное хранятся в `localStorage` (`forma-state-v2`), файлы — в IndexedDB (`forma-files`), телефон — в `sessionStorage`. Телефон не передаётся мастеру или на сервер. Очистка данных сайта удаляет локальные данные. Подтверждённые записи учитываются только в этом браузере; расписание не синхронизировано с CRM.

Цены на примерах — демонстрационные; цена услуги может быть предварительной. Окончательное время и сумма согласовываются клиентом при принятии предложения. Зелёный цвет не используется как основной фирменный акцент.

## Структура

- `dist/index.html` — оболочка и доступная навигация.
- `dist/style.css` — адаптивная дизайн-система, safe area, вертикальные поля даты/времени.
- `dist/app.js` — экраны и обработчики действий.
- `dist/core.js` — поиск, расписание, проверки и переходы заявки.
- `dist/store.js` — проверка формата/размера файла и IndexedDB.
- `dist/seed.js`, `dist/assets/` — исходные демонстрационные данные.
- `tests/core.test.cjs` — проверки бизнес-правил без зависимостей.

Проверки: `node --test tests/core.test.cjs` и `node --check dist/app.js`. Подробности ручной проверки — в `TESTING.md`.
